# AirNudger static website
Buildless Cloudflare Pages site. No package installation or build command needed. Deploy this directory as the output directory. Contains no public APK: current app is privately tested and debug-signed.

For existing direct-upload Pages project airnudger, upload the site contents as one deployment. Verify airnudger.pages.dev before adding airnudger.com in Pages Custom domains. Inspect DNS first and preserve MX, TXT, DKIM, DMARC and unrelated records; change only necessary website routing. Do not deploy this as a Worker or remove the existing Worker.

SEO targets: Fitbit Air notifications; Fitbit Air call alerts; Fitbit Air vibration notifications; Android app for Fitbit Air; custom vibration patterns. These are qualitative search-intent targets, not measured search volumes. Title, description, canonical, social metadata, sitemap and readable FAQ included. No keyword stuffing or fabricated reviews.
